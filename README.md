# Rock Paper Scissors Game 🎮

This is a simple browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript. The player competes against the computer until one reaches 5 points. The game includes buttons for each move and a restart option.

## 🚀 Features

- Play by clicking Rock, Paper, or Scissors buttons
- Computer randomly selects its move
- First to reach 5 points wins the game
- Score is updated after each round
- Restart button to play again


## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript (Vanilla)
